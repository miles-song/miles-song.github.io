Research

My research connects formal verification and cross-layer system simulation with open design questions in AI infrastructure and multi-agent runtimes.

AI systems & infrastructure

How do cluster interconnects, memory hierarchies, and runtime schedulers shape distributed training and inference efficiency? Building on SuperPod communication modeling, I am interested in how transport protocols, collective primitives, and resource multiplexing behave under dynamic AI workloads.

Agent systems

Multi-step tool invocation, external state mutation, and asynchronous message passing make multi-agent workflows difficult to coordinate and debug. I am interested in how execution tracing, state isolation, and formal verification methods can make agent runtimes predictable and verifiable.

Programmable networks & verification

My published research builds verification and hardware-acceleration mechanisms for networked and cloud systems. Using reactive actor modeling, intermediate-representation pruning, logical encoding reduction, and programmable switch pipelines, these systems verify distributed P4 programs, check cloud access-control policies, and accelerate SAT search.

Efficient, Scalable, and Accurate AI Infrastructure Simulation

Building on practical experience in network and communication simulation, I am interested in developing efficient, scalable, and accurate simulation methodologies to analyze the system behavior of modern AI infrastructure.

Simulation of Emerging Interconnect Architectures

This practice involves event-driven simulation of emerging interconnect architectures, modeling cross-layer protocol behavior and communication patterns to examine end-to-end data movement across distributed AI systems.

Open source

Procurator

P4, Boogie, Ultimate/GemCutter

Open-source verifier for distributed stateful P4 systems. Compiles declarative network specifications and imported P4 programs into Boogie harnesses, then invokes Ultimate/GemCutter to check bounded safety properties and emit counterexample witnesses.

Feature Development Skill

Multi-agent orchestration skill

Portable multi-agent orchestration workflow for software feature delivery. Coordinates parallel work packages through explicit interface contracts, non-overlapping file ownership, single-integrator staging, consolidated feature review, and real-boundary runtime verification.

VeriGMP

Rust, Verus

Experimental Rust library for allocation-free multiprecision multiplication, squaring, and modular slice arithmetic. Proves functional refinement in Verus across schoolbook, Karatsuba, Toom-3, and low-product kernels, alongside packed-convolution composition theorems.

ACM SIGCOMM2026

Mingyuan Song, Huan Shen, Jinghui Jiang, Qiang Su, Ziheng Zhang, Qingyu Song, Yuchao Zhang, Wanjian Feng, Fei Yuan, Yitao Xing, Wenjia Wei, Qiao Xiang, Jiwu Shu

LEOPARD: Accelerating Cloud-based Access Control Policy Verification Using Logical Encoding Optimization

IEEE/ACM IWQoS2025

Xing Fang, Feiyan Ding, Mingyuan Song, Yuntao Zhao, Lizhao You, Qiao Xiang, Linghe Kong, Jiwu Shu, Xue Liu

LEOPARD accelerates SMT-based verification of cloud access-control policies through logical encoding optimization, applying structure-based and semantics-based pruning to remove redundant formulas unrelated to the target verification property.

Accelerating SAT Solving Using Switching ASICs

IEEE ICPADS2023

Zhenpei Huang, Xiwen Fan, Jinghui Jiang, Mingyuan Song, Lu Tang, Qiao Xiang, Jiwu Shu

This work offloads Boolean satisfiability solving onto programmable switching ASICs, using match-action tables and TCAM to check variable assignments while driving search through data-plane registers and packet mirroring.
